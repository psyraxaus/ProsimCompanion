Unknown -> ColdAndDark
ColdAndDark -> Preflight
Preflight -> Departure
Departure -> PushbackAndStart
PushbackAndStart -> TaxiOut
TaxiOut -> TakeoffRoll
TakeoffRoll -> InitialClimb
InitialClimb -> Climb
Climb -> Cruise
Cruise -> Descent
Descent -> Approach
Approach -> LandingRollout
LandingRollout -> TaxiIn
TaxiIn -> Shutdown
